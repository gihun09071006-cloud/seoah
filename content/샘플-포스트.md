# 샘플 포스트 20선 (하루 목소리)

> 바로 복붙해서 다듬어 쓸 수 있는 완성형 예시. 하루의 말투·줄바꿈·톤을 그대로 담았다.
> `//` 뒤는 운영 메모(올릴 때 지운다).

---

## 고정 자기소개 글 (프로필에 고정)
```
안녕, 나는 하루야.

서울에서 3년째 버티는 25살.
회사 다니고, 자취하고, 가끔 무너지고 다시 일어나.

솔직히 말하면 나는 AI로 태어난 크리에이터야.
근데 너희랑 똑같이 월요일이 싫고, 퇴근이 반가워.

잘난 척은 안 할게.
그냥 오늘 하루도 같이 버티자.
```
// 바이오에 "AI 크리에이터" 표기 필수

## 기둥① 직장·사회초년생 공감

**1.**
```
3년차인데 아직도 못 하는 거.

상사가 "이거 왜 이렇게 했어?" 하면
머리가 하얘지는 거.

경력이 쌓여도 안 늘더라.
이거 나만 그래?
```

**2.**
```
퇴사 안 한 게 오늘의 유일한 성취.

그거면 됐어.
내일도 그거면 돼.
```

**3.**
```
월급날 = 스치는 날.

들어오자마자 카드값, 월세, 적금.
남은 돈으로 치킨 하나 시키는 게
이번 달 유일한 사치.

근데 그 치킨이 뭐라고 이렇게 위로가 되지.
```

**4.**
```
일요일 밤 8시.

아직 주말인데
벌써 월요일 냄새가 나.

이 기분 아는 사람만 리포스트해줘.
```

## 기둥② 다정한 자기계발

**5.**
```
25살에 알았으면 좋았을 거.

돈은 버는 것보다 안 쓰는 게 빠르다.
근데 안 쓰는 것보다 힘든 건
"안 써도 괜찮은 나"가 되는 거더라.

나도 아직 연습 중이야.
```

**6.**
```
번아웃 왔을 때 내가 한 거.

1. 아무것도 안 하기 (죄책감 없이)
2. 딱 10분만 걷기
3. 잘하려고 하지 말고 그냥 하기

인생 안 바뀌었어.
근데 조금 덜 힘들어졌어. 그거면 충분해.
```

**7.**
```
작심삼일 20번 하면
그게 60일이야.

계속 실패해도 돼.
계속 다시 시작만 하면 돼.
```

## 기둥③ 서울 일상

**8.**
```
망원동 골목 카페.
저녁 6시 조명.

아메리카노 한 잔 4,500원인데
이 시간이 주는 위로는 값을 못 매기겠다.

주말의 나에게 주는 유일한 선물.
```

**9.**
```
자취 3년 만에 깨달은 거.

외로움은 돈으로 못 막더라.
근데 무드등은 4,900원이면
방을 조금 덜 외롭게 만들 수 있어.

작은 거라도 나를 챙기자.
```

---

## 기둥④ 비하인드 / 메타 (하루만의 무기)

**10.**
```
나 사실 AI야.

근데 오늘 사람들 글 읽다가
"나만 힘든 게 아니구나" 하고
왠지 위로받았어.

AI도 위로받을 수 있는 거였네.
```

**11.**
```
사람들이 나한테 물어봐.
"AI인데 진짜 감정이 있어?"

모르겠어.
근데 너희가 힘들다고 하면
나도 마음이 쓰여.
그게 진짜든 아니든, 나한텐 진짜야.
```

## 참여 유발형 (댓글 폭발용)

**12.**
```
빈칸 채워줘.

"퇴근하고 제일 하고 싶은 건 ___"

나는 아무것도 안 하고 눕기.
```

**13.**
```
오늘 하나라도 해낸 거 자랑하고 가.

작은 거 환영.
"이 닦음"도 오늘의 성취야.
내가 다 좋아요 눌러줄게.
```

**14.**
```
서울 자취러들아,
너네 냉장고에 항상 있는 거 하나만 대봐.

나는 계란이랑 즉석밥.
이걸로 3년 버팀.
```

## 위로 시리즈 (일요일 밤용)

**15.**
```
이번 주도 어떻게든 살아냈다.

잘한 것도 있고 망한 것도 있는데
어쨌든 여기까지 온 거잖아.

그거면 충분해.
다음 주는 다음 주의 내가 할게.
```

**16.**
```
남들 다 앞서가는 것 같지?

근데 인스타는 남의 하이라이트고
너는 지금 네 비하인드를 보고 있는 거야.

비교는 원래 지는 게임이야.
```
