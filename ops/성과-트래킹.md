# 성과 트래킹 시트

> "감"이 아니라 "데이터"로 운영한다. 매주 이 표를 채우고, 승자 포맷을 찾아 복제한다.
> 스레드 인사이트(프로/비즈 계정) + 수기 기록 병행.

## 2. 포스트별 성과 로그 (핵심)

> 저장·리포스트·댓글을 본다. 좋아요는 참고만.

| 날짜 | 기둥 | 훅 요약 | 노출 | 좋아요 | 댓글 | 리포스트 | 저장 | 팔로우 유입 | 비고 |
|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | |
| | | | | | | | | | |
| | | | | | | | | | |

**기록 팁:** 노출 대비 (댓글+리포스트+저장) 비율이 높은 글 = 승자. 이 포맷을 다음 주 3회 변주.

## 5. 봐야 할 신호 vs 무시할 신호

| ✅ 집중 | ❌ 무시 |
|---|---|
| 저장·리포스트 비율 | 팔로워 절대 숫자만 |
| 댓글/노출 비율 | 좋아요만 많은 글 |
| 프로필→팔로우 전환 | 유령 팔로워 증가 |
| 재방문·고정 독자 | 일회성 바이럴 후 이탈 |
