## 🎯 이 프로젝트가 뭐야
AI 버추얼 크리에이터 **하루**의 캐릭터 설정부터, 스레드 팔로워를 **어뷰징 없이 빠르게** 성장시키는 전략·콘텐츠·운영 시스템 전부.

- **컨셉:** 사회초년생 공감 + 다정한 자기계발 (한국 스레드 최대 참여 니치)
- **차별점:** "AI인 걸 숨기지 않고 무기로 쓴다" — 법적 안전 + 유니크 포지션
- **북극성:** 팔로워 숫자보다, 댓글에 매일 "이거 완전 내 얘기"가 달리는 계정
